# СМИ Бот · Индия

Telegram-бот для менеджеров: громкие инфоповоды Индии, праздники, фестивали и спортивные события — в едином формате, с карточками-картинками и напоминаниями **заранее** (по умолчанию за 5, 3 и 1 день и ещё раз в день события).

Устроен так же, как бразильский «СМИ Бот»: тот же код и те же команды. Всё, что относится к стране, лежит в трёх файлах папки `data/`:
`country.yaml` (название, штаты, часовой пояс, язык новостей, слова для оценки важности, цвета карточек), `events.yaml` (календарь) и `sources.yaml` (ленты новостей).

## Что умеет

| Что | Когда приходит |
|---|---|
| ⚡ **Срочные новости** (важность 8–10 из 10: смерть звезды, катастрофа, итог финала, громкий скандал) | сразу, круглосуточно — даже ночью |
| 📰 **Дайджест** — 8 главных новостей за сутки с переводом на русский | каждое утро в 09:00 |
| 🗓 **Напоминания** о праздниках, фестивалях, матчах, коммерческих датах | за 5, 3 и 1 день и в день события, в 10:00 |
| 📅 **Обзор недели** | по понедельникам |
| 📍 **Региональное** — местные праздники и новости | только тем, кто выбрал этот штат |

Время — по Дели (IST, на 2,5 часа впереди Москвы), пояс `Asia/Kolkata`. Команды для всех: `/week` `/month` `/news` `/states` `/settings` `/help`.

### Откуда берутся данные
- **Календарь** — `data/events.yaml`: государственные праздники Индии (Дивали, Холи, Дуссера, Ид и др.), праздники штатов (Понгал, Онам, Ганеш-чатуртхи, Дурга-пуджа, Биху, Чхатх…), дни штатов, коммерческие даты (Дхантерас, Ракша-бандхан, День матери…), крикет (Индия — Шри-Ланка, Кубок Бордера — Гаваскара, IPL 2027, чемпионат мира 2027), Кумбха-мела в Нашике.
- **Новости** — RSS-ленты (`data/sources.yaml`): Google Новости (Индия), The Times of India, NDTV, The Hindu, The Indian Express, Hindustan Times, India Today, ESPNcricinfo. Бот опрашивает их каждые 10 минут.

### Как бот понимает, что новость громкая (бесплатно, без ИИ)
1. **Склеивает** одинаковые истории из разных изданий — одна история = одно сообщение.
2. **Считает охват**: чем больше разных изданий подхватили историю, тем она важнее.
3. **Сверяется с трендами Google по стране (IN)**: если тему массово ищут — до +3 баллов.
4. **Учитывает слова**: «dies», «stampede», «cyclone», «wins», «retires» и громкие имена (Моди, Кохли, Шахрукх Кхан, IPL…) повышают важность; гороскопы, лотереи и промо — понижают. Списки слов — в `data/country.yaml`, их можно дополнять.
5. **Определяет тему и штат** («heavy rains lash Kerala» → KL; Дели не размечается — оттуда почти все общенациональные новости).

Важность 8+ — срочное сообщение сразу, 5+ — в утренний дайджест.

**Перевод** — бесплатный онлайн-переводчик MyMemory, с английского на русский. Бот переводит только то, что реально отправляет. Под переводом всегда показывается оригинальный заголовок.

**Платный режим (по желанию, позже).** Если добавить секрет `ANTHROPIC_API_KEY`, бот сам переключится на Claude: точнее отбор, качественный перевод, пояснения и автоматическое добавление в календарь концертов и матчей из новостей. Примерно $1–3 в месяц.

## Запуск на GitHub — так же, как бразильский бот

Это **отдельный бот**: нужен свой токен и свой репозиторий. Бразильский бот это не затрагивает.

1. В Telegram у [@BotFather](https://t.me/BotFather): `/newbot` → имя, например «СМИ Бот · Индия» → получите **новый токен**.
2. На GitHub: *New repository* → имя, например `smi_india_bot` → **Public** → *Create repository*.
3. *uploading an existing file* → перетащите **содержимое** папки `smi_india_bot` (папки `bot`, `data`, `assets`, `tests` и файлы) → *Commit changes*.
   Папка `.github` скрытая и может не перетащиться. Тогда: *Add file → Create new file*, в имени файла введите `.github/workflows/bot.yml`, вставьте содержимое этого файла из архива → *Commit changes*.
4. *Settings → Secrets and variables → Actions → New repository secret*:
   - `BOT_TOKEN` — **новый** токен этого бота;
   - `ADMIN_IDS` — ваш Telegram ID (тот же, что у бразильского бота);
   - `STATE_KEY` — новый длинный пароль (20+ символов) для шифрования базы этого бота;
   - по желанию `TRANSLATE_EMAIL` (можно ту же почту) и `ACCESS_CODE`.
5. Вкладка *Actions* → если просит, *I understand… enable them* → слева **smi-bot** → *Run workflow*.
6. Через минуту в Telegram: `/start` → выбрать штаты → `/fetch` → `/test`.

Если что-то не работает — лог запуска в *Actions*, а в боте `/sources` (какие ленты отвечают) и `/stats`.

Настройки (время рассылок, дни напоминаний) — во вкладке *Variables*: `TIMEZONE`, `REMIND_TIME`, `DIGEST_TIME`, `REMIND_DAYS`, `BREAKING_THRESHOLD`. Если `TIMEZONE` не задан, используется пояс страны (`Asia/Kolkata`).

> GitHub отключает расписание в репозитории, где 60 дней не было изменений, и присылает письмо — достаточно нажать *Enable workflow* или сделать любую правку.

## Запуск на своём сервере

Как у бразильского бота: `cp .env.example .env`, вписать `BOT_TOKEN` и `ADMIN_IDS`, затем `docker compose up -d --build`. Несколько ботов (Бразилия, Индия, Филиппины) могут работать на одном сервере — у каждого своя папка и своё имя контейнера. Без Docker: `pip install -r requirements.txt && python -m bot.main`.

## Календарь

Большинство индийских праздников идут по лунному календарю, их даты каждый год разные. В календаре они записаны конкретными датами до конца 2027 года — по официальному списку праздников правительства Индии (DoPT) на 2026 и 2027 годы. Исламские праздники могут сдвинуться на день по луне. Летом 2027 правительство опубликует список на 2028 год — тогда в `events.yaml` нужно добавить даты на 2028 год (сам бот об этом не напомнит). Фиксированные даты (День Республики, День независимости, дни штатов) продлеваются сами.

### Добавить событие
- **Из Telegram** (администратор): `/add 20.12.2026 | Концерт Arijit Singh в Мумбаи | MH | festival | NSCI Dome`
  Диапазон дат: `05.02.2027-10.02.2027`. Категории: `holiday`, `festival`, `sport`, `commercial`, `culture`.
- **Насовсем**: допишите блок в `data/events.yaml` (формат описан в начале файла) и отправьте боту `/reload`.

## Устройство проекта
```
bot/                 код (общий для всех стран)
  country.py         загрузка профиля страны
data/country.yaml    профиль страны: штаты, пояс, язык, слова для оценки, цвета
data/events.yaml     календарь (редактируется)
data/sources.yaml    RSS-ленты (редактируется)
tests/               python -m unittest discover -s tests
```

Даты событий сверены с открытыми источниками на 9 ноября 2026. Шрифт Inter — лицензия SIL OFL 1.1 (`assets/fonts/OFL.txt`).
